# satuuu99

A bilingual wellness studio website built with React, TypeScript, Vite and Tailwind CSS.

```sh
npm ci
npm run dev
```

`npm run build` type-checks and creates `dist`. `npm run preview` serves the production build. `npm run format` formats source; `npm run format:check` checks it.

- `src/data/content.ts`: services, bilingual copy, contact and booking destinations.
- `src/data/media.ts`: current media sources and future generated assets.
- `src/index.css`: design tokens, layout, responsive styles and interaction states.
- `src/sections/`: homepage sections.
- `docs/DESIGN.md`: audit, changes, reference sources, limitations and recovery notes.
- `docs/ASSET-BRIEF.md`: prepared Magnific / Recraft art direction and shot list.

The visual redesign is implemented locally. Media are Magnific generations: stills with Recraft V4.1, the hero loop with Kling 3.0 from the approved hero still. See `docs/ASSET-BRIEF.md` for the creation record. Booking links open the existing Satuuu site. Nothing has been deployed.
